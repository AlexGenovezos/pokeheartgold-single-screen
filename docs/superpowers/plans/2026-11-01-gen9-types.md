# Modern type foundation implementation plan

> **For agentic workers:** Use executing-plans for this foundation; isolated
> implementation/review tasks may use the available subagent tools. Do not
> request another approval for the already selected Gen IX scope.

**Goal:** Make Fairy species/move typing and the modern shared chart work from a
reproducible ROM/native build, behind an explicit development flag.

**Architecture:** Preserve type slot count and save structures. Slot 9 becomes
Fairy with `QOL_MODERN_TYPES=1` (default 0 until integration is complete). Source
loaders adjust runtime personal and move data. A post-build ROM transform replaces
only type-name and icon resources; the original filesystem inputs remain intact.
Damage, AI and effectiveness previews retain their shared chart.

**Tech Stack:** Existing C game source and compiler, Python standard library,
NitroFS/NARC/message formats, existing native layout generator.

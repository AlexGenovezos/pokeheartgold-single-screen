# Modern Simple and six X items

Approved scope: ordinary Gen IX rules for the original roster, with the original
story, save/native ABI and flag-off behavior retained. The detailed source audit
and preimplementation checklist are retained in ignored
`.local-tools/validation/modern-simple-plan.md` and
`.local-tools/validation/gen9-simple-implementation-plan.md`.

## Implementation

- A pure `Qol_GetActualStatStageDelta` computes one clamped semantic delta. Active
  modern Simple doubles new changes, including positive and negative changes;
  gaining, losing or suppressing the ability never reinterprets stored stages.
- Central stat changes apply that delta only after existing failure checks. Only
  actual external direct/indirect move sources can borrow their own active Mold
  Breaker, including positive Swagger/Flatter. Ability, item and self changes do
  not inherit the current attacker's ability. Existing Competitive marker bit0
  and subscript12's stack-safe presentation298 tail remain unchanged.
- Modern speed, damage and accuracy/evasion consume stored stages once. The six
  legacy Simple interpretation branches are retained verbatim behind flag-off.
- Original script arithmetic is audited as three ADD sites (Future Sight Rage,
  Motor Drive, dynamic-TEMP Starf) and four Stockpile SUB_TO_ZERO sites (effects
  161/162, which are Spit Up/Swallow). TEMP resolves before classification. Only
  ATK through EVASION ADD/SUB/SUB_TO_ZERO use semantic deltas; GET, SET, copies,
  swaps, resets and the low-level setters remain exact.
- Stockpile counts successful gain events once. Its loss uses the current active
  ability: Simple throughout gives +2 then -2; losing it gives +2 then -1;
  gaining it gives +1 then -2. Cap clipping does not turn an event into a larger
  counter. Existing script counters are unchanged.
- Each of six X items uses modern base +2, Simple +4, and cap clipping. Player bag
  application remains immediate and controls consumption through its existing
  success result. Trainer opcode187 captures its single application's before and
  after stages locally; modern script269 prints that buffered actual message.
  Dire Hit remains Focus Energy, outside the stage hook.

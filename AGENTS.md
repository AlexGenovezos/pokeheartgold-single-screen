# Quality-of-life mods

- Before implementing a new mod, search existing HGSS mods and relevant upstream
  sources. Record the source links, inspected revision, compatibility findings
  and reuse decision in `docs/QOL-REUSE.md` and the feature's GitHub issue.
- Prefer an existing implementation when it fits the requested behavior and
  this SoulSilver single-screen/native build. Verify the actual code and reuse
  terms; a repository name or feature list alone is not implementation evidence.
- Keep ports focused on the requested change. Preserve the agreed story,
  Pokémon roster and save compatibility when considering a broader mod bundle.
